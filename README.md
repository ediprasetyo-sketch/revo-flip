# Revo Flip

Revo Flip V1 is a web platform for uploading large learning PDFs and opening them in a flipbook-style viewer.

## V1 scope

- PDF upload target up to 10 GB
- Resumable multipart upload architecture
- Cloudflare R2 object storage
- Cloudflare D1 metadata storage
- Material catalog and search
- Flipbook viewer foundation
- Shareable material links

The application files will be added in the next commits.
